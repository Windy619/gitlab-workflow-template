Ce repo fournit une base GitLab standardisée à appliquer sur n'importe quel nouveau projet : une taxonomie de labels en quatre axes (domaine, priorité, type, workflow), un board Kanban avec limites WIP, des milestones et des templates d'issue/MR cohérents entre eux. Tout se déploie via un script API (setup\_gitlab\_template.py), sans passer par l'import/export de projet.
